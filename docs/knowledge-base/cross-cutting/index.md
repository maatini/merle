# Cross-Cutting — Modulübergreifende Konzepte

Dieser Ordner enthält Konzepte, die in mehreren Modulen auftauchen und nicht einem einzelnen Modul zugeordnet werden können.

- **[`tags.md`](./tags.md)** — Vollständige @tag-Registry. Jeder Tag definiert ein wiederkehrendes Konzept mit einer einzeiligen Bedeutung.
- **[`shared-patterns.md`](./shared-patterns.md)** — 5 zentrale Architekturmuster, die in allen Bots und im Template verwendet werden.
