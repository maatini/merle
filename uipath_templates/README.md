# UiPath Templates

Dieses Verzeichnis enthält UiPath-Templates für die **Ausnahmefälle**, in denen UiPath nachweislich die bessere Wahl ist (siehe `docs/02_Wann_Python_vs_UiPath.md`).

## Wichtiger Hinweis

> **UiPath ist die Ausnahme, nicht die Regel.**  
> In 80–90 % der Fälle wird Python verwendet. Dieses Verzeichnis existiert nur für die dokumentierten Ausnahmefälle.

## Enthaltene Templates

Aktuell keine — Templates werden bei Bedarf ergänzt, wenn ein Ausnahmefall eintritt.

## Typische UiPath-Use-Cases (Ausnahmen)

1. Legacy-Desktop-UI-Automatisierung (nach gescheitertem Python-Prototyp)
2. High-End Document Understanding
3. Enterprise Orchestration mit HITL
